My first production RAG system hallucinated a Supreme Court citation that didn't exist. The lawyer caught it during final review—the case name sounded plausible but the docket number was from a different circuit.

We'd spent three weeks tuning the embedding model, chunking strategies, and re-ranking. The recall@5 was 92%. Precision wasn't the problem. The model was *too confident* in wrong answers.

<Callout label="Debug output">
The model's internal logits showed 0.98 confidence for "ninth circuit" when the actual case was second circuit. The retrieval had found similar cases, but the generation didn't check the metadata.
</Callout>

The fix wasn't more data or a bigger model. It was:

```python
def verify_citation(response, retrieved_docs):
    for claim in extract_citations(response):
        if not any(claim in doc.metadata for doc in retrieved_docs):
            return False, claim
    return True, None
```

A 14‑line function that ran after generation caught 83% of hallucinations before they reached the lawyer.

Sometimes the solution isn't in the loss function. It's in the verification layer you add after the model finishes thinking.
